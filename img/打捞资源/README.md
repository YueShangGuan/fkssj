# 打捞资源模板

请在目标设备的 **1080×2400 原始游戏截图** 中裁取并放入此目录：

- `钓鱼.png`：地图物体点击后出现的“钓鱼”按钮。
- `拾荒.png`：地图物体点击后出现的“拾荒”按钮。
- `打捞.png`：地图物体点击后出现的“打捞”按钮。
- `甩杆.png`：不限时钓鱼结束判断用的“甩杆”图标。
- `钓鱼设施.png`：点击“前往”并双指缩小两次后，用于定位钓鱼船的设施主体。
- `拾荒设施-状态一.png`、`拾荒设施-状态二.png`：拾荒船的两个可见动画状态；任一命中都点击模板中心。
- `下潜设施.png`：下潜打捞浮台的稳定围栏、平台和护栏组合，不包含白色引导手势。

入口按钮与设施模板不能互相替代。设施模板须从目标设备的原始地图截图裁取，并在脚本执行“前往 → 双指缩小两次”后的统一比例下使用；模板缺失时脚本会安全跳过对应类别，不会点击不确定的游戏元素。
