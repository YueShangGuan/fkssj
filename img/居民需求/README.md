# 居民需求模板

模板均裁自 `D:\Documents\MuMu共享文件夹\Screenshots\居民需求` 的 1080×2400 原始截图：

- 居民入口不再使用单一头像模板：当前第一位居民会改变头像。`residentDemand.js` 以 `img/贸易港口/入口.png` 未被绿色勾遮挡的上半部为锚点，并点击该锚点左上角下方 `(40, 152)` 的居民头像槽位；点击后必须识别到需求面板才会继续。`入口.png` 仅保留为原始排障截图素材，不参与运行时识别。
- `面板标识.png`、`满足TA.png`、`刷新.png`、`返回.png`：`展开后出现抽屉，居民需求界面，.png`。
- `立即完成.png`：`正在刷新需求.png`；只用来确认协商中，自动化绝不点击它。

`residentDemand.js` 会额外用固定奖励与物资数字区域的 OCR / 红色像素检查确认业务语义，模板本身不承担数值判断。
